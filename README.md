A web-based Disaster Alert and Emergency Management System designed to help users report emergencies, view disaster-related information, and allow administrators to monitor and manage emergency requests in real time.

The system provides a user-friendly platform for submitting emergency requests with location details and allows administrators to view, manage, and assign emergency requests through an interactive dashboard.

FEATURES
User Registration and Login
Secure user authentication
Emergency help request form
Selection of disaster type
Location input support
Latitude and longitude capture
Number of people affected
Emergency description
View previously submitted emergency requests
Track the status of submitted requests
Logout functionality
